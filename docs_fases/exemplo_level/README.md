# DIRETÓRIO DE EXEMPLO DE NÍVEL — LEVANTE 13

Esta pasta contém a estrutura completa e validada de assets exigida para um nível operacional:

1. **`config.json`**: Arquivo de parametrização da missão (mentoria, grade, inimigos, chefe, cores).
2. **`bg.png`**: Imagem de fundo cósmico / atmosférico do setor (recomendado: 480x720 ou proporção vertical similar).
3. **`enemy.png`**: Sprite base da frota inimiga regular da grade.
4. **`boss.png`**: Sprite da Capitânia / Chefe do setor (dimensões de casco aproximadas: 76x50px ou 96x64px).
5. **`mentor.png`**: Retrato do comissário ou mentor da resistência para a holotransmissão (recomendado: 120x120px ou similar, estilo pixel art).

Consulte o **MANUAL DE INSTRUÇÃO TÁTICA (PDF)** localizado na pasta mãe para detalhes completos de cada parâmetro e mecânica.
